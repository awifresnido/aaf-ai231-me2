# Evaluation

## Slices

- **Awi s02** — the author's held-out validation session.
- **Gold test speaker `201435283`** — the unseen group test speaker.
- **Single-Words FAR** — clean single-word utterances (false-accept rate).
- **holdout** — the class holdout: 202 clips = 84 real takes from unseen speaker
  `202520785` + 100 synthetic from two held-out voices + 16 out-of-scope +
  2 paraphrase, plus Awi's s03.
- **τ-set** — used to fix the deployment threshold τ = 0.95.

## Release gate (pre-registered)

A fine-tuned model replaces its v1 parent only if **all four** conditions hold:

1. per-seed wrong-rate ≤ 1 % on the τ-set;
2. Awi s02 correct ≥ v1 − 1 pt;
3. group test speaker `201435283` correct ≥ v1 + 5 pt;
4. Single-Words FAR ≤ v1 + 1 pt.

## Verdict (`decision.json`)

`replace_v1 = false` for **all three** fine-tunes — condition (2) failed for
every one:

| Model | (1) wrong≤1% | (2) Awi s02 ≥ v1−1pt | (3) group spk ≥ v1+5pt | (4) FAR ≤ v1+1pt | Verdict |
|---|---|---|---|---|---|
| B2f | ✓ 0.05 % | ✗ −5.0 pt | ✗ +1.9 pt | ✓ | keep B2 |
| E1f | ✓ 0.0 % | ✗ −2.9 pt | ✓ +17.7 pt | ✓ | keep E1 |
| G2f | ✓ 0.03 % | ✗ −6.5 pt | ✗ +1.1 pt | ✓ | keep G2 |

### Logged deviation

> The rule says retain v1, but **E1f_s1 was still deployed as the app default**:
> the fine-tune lifts the group test speaker by +17.7 pt and cuts Single-Words
> FAR 2.06 % → 0.58 %, at the cost of a 2.9 pt Awi-s02 regression that the
> rule's floor forbids. B2f_s0 kept as secondary; G2f not exported.

This deviation is stated verbatim here and in `results/me2_gold/decision.json`;
it is **not** softened or omitted.
